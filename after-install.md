# AI Cyber Value Creator™ installed

1. **Enable it** (if you didn't pass `--enable`):
   `hermes plugins enable ai-cyber-value-creator`
2. **Restart hermes**, then open the dashboard — the **Value Creator** tab has
   the roadmap.
3. **Start the gateway** so step tasks can run as sessions:
   `hermes gateway start`
4. Begin with the foundation: click **+ Task** on *Get Clarity on the ICP*
   (or run `/value-step create-value-icp`). Open the task's thread and work it
   with the agent — it records confirmed answers into the shared Company
   Context as you go.

`/value-creator` shows roadmap status in any session.
